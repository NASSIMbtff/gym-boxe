# Projet Gym Boxe

## Description
Ce site web présente un gym spécialisé dans la boxe. Vous y trouverez :
- Des informations sur le gym et ses services.
- Une liste des événements à venir (compétitions, entraînements, etc.).
- Un formulaire pour s'inscrire à des séances.

## Palette de couleurs
- Rouge : #ff4d4d
- Blanc : #ffffff
- Gris : #cccccc
- Noir : #000000

## Wireframes
1. **Page d’accueil** : 
   - Titre : "Bienvenue au Gym de Boxe !"
   - Description : Une brève introduction sur le gym.
   - Menu de navigation : Accueil, Événements, Contact.

2. **Page des événements** :
   - Liste des événements avec nom, date, et description.

3. **Formulaire d’inscription** :
   - Champs : Nom, email, type de séance.
